# فورک بومی بارنامه شهری

یک بازپیاده‌سازی تمیز React Native/Expo از مسیرهای اصلی اپ اندروید: ورود، صفحه اصلی، تاریخچه اسناد، اسناد در حال حمل و ثبت شروع/پایان حمل. این پروژه جایگزین WebView موجود در `base-2-rebuild` است و به‌صورت مستقل نگه‌داری می‌شود.

## وضعیت فعلی

- رابط فارسی و راست‌به‌چپ با رنگ‌ها، فونت و تصاویر استخراج‌شده از APK اصلی.
- APK و تنظیمات پیش‌فرض از ورود واقعی استفاده می‌کنند. برای تست آفلاین می‌توان `EXPO_PUBLIC_DEMO_MODE=true` کرد؛ در این حالت هیچ درخواست واقعی ثبت/پایان حمل ارسال نمی‌شود.
- ورود زنده و API اسناد پیاده‌سازی شده‌اند، اما endpoint و سرآیندهای مجاز سرویس از این محیط تأیید نشده‌اند؛ نتیجه ورود واقعی هنوز روی حساب کاربر آزمایش نشده است.
- تب اتوماسیون Gemini از مدل سریع `gemini-2.5-flash` و function calling استفاده می‌کند. کلید را در تنظیمات وارد کنید؛ فقط ابزارهای پیاده‌سازی‌شده در فهرست مجاز در دسترس مدل هستند.
- اجازه کلی ابزارها در تنظیمات پیش‌فرض خاموش است؛ پس از فعال‌سازی، عملیات بدون تأیید جداگانه اجرا می‌شوند و با خروج از حساب لغو می‌شوند. مجوز GPS اندروید را خود کاربر در سیستم‌عامل می‌دهد.
- مسیرهای فرعی مانند پرداخت، سوخت، پیام‌ها و فرم کامل صدور بارنامه فعلاً نمایشی/جای‌نگهدار هستند.

## پیش‌نیاز و اجرا

Node.js، npm و Android Studio با Android SDK لازم است. این workspace ابزار npm/Gradle/Java ندارد؛ APK در GitHub Actions ساخته می‌شود.

```sh
cp .env.example .env
npm install
npx expo prebuild --platform android
npx expo run:android
```

برای اجرای نسخه آزمایشی، `EXPO_PUBLIC_DEMO_MODE=true` تنظیم کنید. ورود واقعی با همان فرم کد ملی/رمز عبور موجود در اپ انجام می‌شود. کلید Gemini با SecureStore روی دستگاه نگه‌داری می‌شود و برای درخواست Gemini از همان دستگاه استفاده می‌شود. اسرار سرویس را در `EXPO_PUBLIC_*` نگذارید؛ متغیرهای عمومی Expo داخل برنامه نهایی قرار می‌گیرند.

## ساخت APK با GitHub Actions

با هر push به شاخه `main` یا اجرای دستی workflow با نام `Android APK`، GitHub تست‌ها را اجرا و یک APK مستقل می‌سازد که JavaScript را درون خود دارد و به Metro نیاز ندارد. فایل `app-debug.apk` را از بخش Artifacts همان اجرای workflow دریافت کنید. این build برای آزمایش است و از کلید انتشار شخصی استفاده نمی‌کند؛ صفحه ورود واقعی فعال است.

## GPS پس‌زمینه

برای ادامه جمع‌آوری مسیر در زمان قفل بودن صفحه، build توسعه‌ای/نهایی لازم است؛ Expo Go کافی نیست. هنگام شروع حمل، برنامه مجوز GPS و پس‌زمینه را جداگانه درخواست می‌کند و اعلان foreground service اندروید نشان می‌دهد. توقف/پایان حمل باید از داخل برنامه انجام شود.

## پوشه‌ها

- `src/screens`: ورود، خانه، فهرست اسناد و جزئیات حمل.
- `src/api`: کلاینت شبکه و قراردادهای احراز هویت/سند/حمل.
- `src/services`: نگه‌داری امن token و جمع‌آوری GPS.
- `src/automation`: ابزارهای محدود، سیاست مجوز کلی و ثبت ممیزی.
- `src/screens/GeminiAutomationScreen.js`: گفتگوی Gemini و فهرست کارهای زمان‌بندی‌شده.
- `src/automation/scheduleRunner.js`: اجرای صف محلی در foreground و background best-effort اندروید.
- `reference`: نقشه دیکامپایل و نسخه مرجع پاک‌سازی‌شده از مقادیر حساس.
- `tests`: آزمون‌های قرارداد payload و سیاست مجوز کلی اتوماسیون.

کلید Gemini و مجوز کلی ابزارها در صفحه «تنظیمات و حساب» مدیریت می‌شوند. زمان‌بندی بر اساس منطقه زمانی گوشی ذخیره می‌شود؛ Android ممکن است اجرای پس‌زمینه را به تعویق بیندازد و اجرای دقیق رأس دقیقه تضمین‌شده نیست. شرح مرز ابزارها و محدودیت‌ها در `docs/automation-contract.md` است.
