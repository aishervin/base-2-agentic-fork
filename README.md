# فورک بومی بارنامه شهری

یک بازپیاده‌سازی تمیز React Native/Expo از مسیرهای اصلی اپ اندروید: ورود، صفحه اصلی، تاریخچه اسناد، اسناد در حال حمل و ثبت شروع/پایان حمل. این پروژه جایگزین WebView موجود در `base-2-rebuild` است و به‌صورت مستقل نگه‌داری می‌شود.

## وضعیت فعلی

- رابط فارسی و راست‌به‌چپ با رنگ‌ها، فونت و تصاویر استخراج‌شده از APK اصلی.
- نسخه نمایشی به‌صورت پیش‌فرض فعال است؛ در حالت نمایشی هیچ درخواست واقعی شروع/پایان حمل ارسال نمی‌شود.
- قراردادهای API و GPS پیاده‌سازی شده‌اند، اما دسترسی backend از محیط ساخت قابل تأیید نبود. برای استفاده واقعی، روش مجاز دریافت سرآیندهای سرویس باید فراهم شود.
- لایه ابزارهای اتوماسیون آماده است، اما مدل زبانی یا سرویس ایجنتی در پروژه تعبیه نشده است. اجازه کلی اتوماسیون در تنظیمات پیش‌فرض خاموش است؛ پس از فعال‌سازی، شروع/پایان حمل تأیید جداگانه نمی‌خواهد و با خروج از حساب لغو می‌شود.
- مسیرهای فرعی مانند پرداخت، سوخت، پیام‌ها و فرم کامل صدور بارنامه فعلاً نمایشی/جای‌نگهدار هستند.

## پیش‌نیاز و اجرا

Node.js، npm و Android Studio با Android SDK لازم است. این workspace ابزار npm/Gradle/Java ندارد؛ APK در اینجا ساخته نشده است.

```sh
cp .env.example .env
npm install
npx expo prebuild --platform android
npx expo run:android
```

برای اجرای نسخه آزمایشی، `EXPO_PUBLIC_DEMO_MODE=true` بماند. اتصال واقعی را فقط پس از تأیید API و فراهم‌کردن سرآیندهای مجاز فعال کنید. اسرار سرویس را در `EXPO_PUBLIC_*` نگذارید؛ متغیرهای عمومی Expo داخل برنامه نهایی قرار می‌گیرند. اگر backend سرآیند سرویس می‌خواهد، آن‌ها باید از یک واسط امن متعلق به شما صادر شوند.

## ساخت APK با GitHub Actions

با هر push به شاخه `main` یا اجرای دستی workflow با نام `Android APK`، GitHub تست‌ها را اجرا و یک APK آزمایشی مستقل می‌سازد که JavaScript را درون خود دارد و به Metro نیاز ندارد. فایل `app-debug.apk` را از بخش Artifacts همان اجرای workflow دریافت کنید. این build برای آزمایش است و از کلید انتشار شخصی استفاده نمی‌کند؛ حالت نمایشی فعال است.

## GPS پس‌زمینه

برای ادامه جمع‌آوری مسیر در زمان قفل بودن صفحه، build توسعه‌ای/نهایی لازم است؛ Expo Go کافی نیست. هنگام شروع حمل، برنامه مجوز GPS و پس‌زمینه را جداگانه درخواست می‌کند و اعلان foreground service اندروید نشان می‌دهد. توقف/پایان حمل باید از داخل برنامه انجام شود.

## پوشه‌ها

- `src/screens`: ورود، خانه، فهرست اسناد و جزئیات حمل.
- `src/api`: کلاینت شبکه و قراردادهای احراز هویت/سند/حمل.
- `src/services`: نگه‌داری امن token و جمع‌آوری GPS.
- `src/automation`: ابزارهای محدود، سیاست مجوز کلی و ثبت ممیزی.
- `reference`: نقشه دیکامپایل و نسخه مرجع پاک‌سازی‌شده از مقادیر حساس.
- `tests`: آزمون‌های قرارداد payload و سیاست مجوز کلی اتوماسیون.

برای فعال‌سازی/لغو مجوز کلی از صفحه «تنظیمات و حساب» استفاده کنید. مجوز GPS و سرویس پس‌زمینه نیز هنگام نیاز توسط اندروید درخواست می‌شود. شرح نقشه دیکامپایل در `reference/DECOMPILATION_MAP.md` و مرز ایجنت در `docs/automation-contract.md` است.
