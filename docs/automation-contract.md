# قرارداد ابزارهای اتوماسیون

این پروژه فقط مرز ابزارها را آماده می‌کند؛ هنوز هیچ LLM یا اتصال ابری ایجنتی ندارد.

- `listShipments`: خواندنی.
- `prepareTripStart`: خواندنی/آماده‌سازی GPS؛ درخواست ثبت نمی‌فرستد.
- `startTrip`: تغییردهنده و نیازمند تأیید صریح همان عملیات.
- `prepareTripEnd`: مسیر ذخیره‌شده و موقعیت نهایی را آماده می‌کند؛ ثبت نمی‌فرستد.
- `endTrip`: تغییردهنده و نیازمند تأیید صریح همان عملیات.

توکن و کد ملی به ایجنت بازگردانده نمی‌شود. هر عملیات تغییردهنده با زمان، نوع عمل و شناسه سند ثبت ممیزی می‌شود. برای اتصال ایجنت، backend متعلق به پروژه باید احراز هویت، مجوز کاربر، محدودیت تکرار و idempotency را نیز اعمال کند.
