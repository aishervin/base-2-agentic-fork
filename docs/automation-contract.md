# قرارداد ابزارهای اتوماسیون

این پروژه مرز ابزارها و مجوز کلی اتوماسیون را آماده می‌کند؛ هنوز هیچ LLM یا اتصال ابری ایجنتی ندارد.

- `listShipments`: خواندنی.
- `prepareTripStart`: خواندنی/آماده‌سازی GPS؛ درخواست ثبت نمی‌فرستد.
- `startTrip`: تغییردهنده؛ پس از فعال‌سازی اجازه کلی در تنظیمات، بدون تأیید جداگانه اجرا می‌شود.
- `prepareTripEnd`: مسیر ذخیره‌شده و موقعیت نهایی را آماده می‌کند؛ ثبت نمی‌فرستد.
- `finishTrip`: تغییردهنده؛ پس از فعال‌سازی اجازه کلی در تنظیمات، بدون تأیید جداگانه اجرا می‌شود.

اجازه کلی به‌صورت محلی ذخیره می‌شود، پیش‌فرض خاموش است و با خروج از حساب لغو می‌شود. مجوز GPS اندروید جداگانه توسط سیستم‌عامل گرفته می‌شود. توکن و کد ملی به ایجنت بازگردانده نمی‌شود. هر عملیات تغییردهنده با زمان، نوع عمل و شناسه سند ثبت ممیزی می‌شود. برای اتصال ایجنت، backend متعلق به پروژه باید احراز هویت، مجوز کاربر، محدودیت تکرار و idempotency را نیز اعمال کند.
