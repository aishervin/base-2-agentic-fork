# مرجع اپ اصلی

در بسته منبع محلی، فایل `decompiled/index.android.bundle.decompiled.js` نسخه مرجع دیکامپایل‌شده است. پیشوند/پسوند سرآیند سرویس و مقدار کلید رمزنگاری از آن پاک‌سازی شده‌اند. این فایل بزرگ در ریپازیتوری GitHub نگه‌داری نمی‌شود و برای build لازم نیست؛ مقادیر تعبیه‌شده در برنامه اصلی را به فورک یا APK تازه منتقل نکنید.

این فایل خروجی دیکامپایل Hermes است، نه کد منبع مرتب و قابل build. پیاده‌سازی تمیز در `src/` قرار دارد.
